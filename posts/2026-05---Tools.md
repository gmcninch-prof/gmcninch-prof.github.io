I have a recent interest in formalizing mathematics in `Lean4`. But I
thought it would be useful to try to do relatively ordinary computer
programming tasks in `Lean`, as a learning experience. (I should point
out that I come to this already as a bit of functional programming fan.)

# MLML

So: I built a small tokenizer-parser-decoder configuration language
that I called [`MLML`](https://github.com/gmcninch-prof/mlml). (I used
to use `dhall` for tasks like this, but don't need all its features
and thought it would be educational and interesting to write my own.)

The
[README](https://github.com/gmcninch-prof/mlml/blob/main/README.md) at
the repository has a bit of an overview of the specifications.

# course-planner

One frequent task when teaching is to produce semester schedule(s)
for aspects of a course. 

I used the `MLML` configuration language to provide course-planning
tools for this requirement: see the repository here:
[course-planner](https://github.com/gmcninch-prof/course-planner)

This tool uses an `MLML` `semester specification` -- see e.g.  [this
example](https://github.com/gmcninch-prof/course-planner/blob/main/Test/semester-specs/AY2025-2026.mlml) --
together with an `MLML course specification` -- see e.g.  [this
example](https://github.com/gmcninch-prof/course-planner/blob/main/Test/math136-spring26.mlml)
-- to produce `markdown` descriptions of the schedule -- see e.g.
[the lecture schedule for this
sample class](https://github.com/gmcninch-prof/course-planner/blob/main/Test/lectures.md)
and the [org-mode schedule info for this sample class](https://github.com/gmcninch-prof/course-planner/blob/main/Test/Math136--AY2025-2026--Spring.org).



# publications

I wrote a tool to use `MLML` to keep track of publication information,
as well; see the repository here:
[pubs](https://github.com/gmcninch-prof/pubs)

Using an `MLML` specification, this tool actually produces
the publication-list [part of my CV](/assets/curriculum-vita-short.pdf)
and the [publication-list part of this web-site](/pages/manuscripts.html).

Here is an example of an [`MLML` specification of a few
manuscripts](https://github.com/gmcninch-prof/pubs/blob/main/Test/test.mlml).

And here are the two forms of output from this data:

- [manuscript details](https://github.com/gmcninch-prof/pubs/blob/main/Test/manuscripts.md)
- [cv style output](https://github.com/gmcninch-prof/pubs/blob/main/Test/manuscripts.md)
