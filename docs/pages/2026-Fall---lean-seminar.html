References

The Lean prover community website has lots of Lean resources.

In particular, probably the first thing you need to know is how to install Lean on your computer. Note that you really do need to carry out all the steps in this installation process to have a working copy of Lean on your computer.

Before installation, you might try using this online version of Lean.
